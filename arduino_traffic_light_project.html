상태 0 · 대기

빨간불 켜짐

전원이 켜지면 빨간 LED가 켜지고 버튼 입력을 기다립니다.

상태 1 · 전환

노란불 2초

빨간불 상태에서 버튼을 누르면 노란 LED가 켜집니다.

상태 2 · 진행

초록불 켜짐

노란불이 2초 유지된 후 초록 LED로 바뀝니다.

추가 동작: 초록불 상태에서 버튼을 누르면 빨간불로 즉시 돌아갑니다.

3. 핀 연결 및 주요 변수

부품 / 변수설정역할
빨간 LEDD8대기 상태 표시
노란 LEDD9전환 상태 표시
초록 LEDD10진행 상태 표시
버튼D2INPUT_PULLUP으로 입력 읽기
DEBOUNCE_DELAY50ms버튼 접점의 짧은 흔들림을 무시
YELLOW_TIME2000ms노란불 유지 시간 2초

버튼 입력 참고: INPUT_PULLUP을 사용하므로 일반적인 연결에서는 버튼을 누를 때 LOW, 누르지 않을 때 HIGH가 읽힙니다.

4. 전체 아두이노 코드

const int RED = 8;
const int YELLOW = 9;
const int GREEN = 10;  // 초록불 역할
const int BUTTON = 2;

// 신호등 상태: 0 = 빨간불(대기), 1 = 노란불(전환 중), 2 = 초록불(유지)
int trafficState = 0;

bool lastReading = HIGH;
bool stableButton = HIGH;
unsigned long debounceTime = 0;
unsigned long yellowStart = 0;

const unsigned long DEBOUNCE_DELAY = 50;
const unsigned long YELLOW_TIME = 2000;  // 노란불 유지 시간: 2초

void setLights(bool red, bool yellow, bool green) {
  digitalWrite(RED, red);
  digitalWrite(YELLOW, yellow);
  digitalWrite(GREEN, green);
}

void setup() {
  pinMode(RED, OUTPUT);
  pinMode(YELLOW, OUTPUT);
  pinMode(GREEN, OUTPUT);
  pinMode(BUTTON, INPUT_PULLUP);

  // 처음 시작은 빨간불 유지
  setLights(HIGH, LOW, LOW);
}

void loop() {
  bool reading = digitalRead(BUTTON);

  // 버튼 디바운싱 처리: 입력 변화가 감지되면 시간 기록
  if (reading != lastReading) {
    debounceTime = millis();
  }

  if ((millis() - debounceTime) > DEBOUNCE_DELAY) {
    if (reading != stableButton) {
      stableButton = reading;

      // 빨간불(상태 0)일 때 버튼을 누르면 노란불로 진입
      if (stableButton == LOW && trafficState == 0) {
        trafficState = 1;
        yellowStart = millis();
        setLights(LOW, HIGH, LOW);
      }
      // 초록불(상태 2)일 때 버튼을 누르면 빨간불로 즉시 복귀
      else if (stableButton == LOW && trafficState == 2) {
        trafficState = 0;
        setLights(HIGH, LOW, LOW);
      }
    }
  }

  lastReading = reading;

  // 노란불 상태에서 2초가 지나면 초록불로 변경
  if (trafficState == 1 && (millis() - yellowStart) >= YELLOW_TIME) {
    trafficState = 2;
    setLights(LOW, LOW, HIGH);
  }
}

5. 코드에서 중요한 부분

setLights()

세 LED의 켜짐/꺼짐 상태를 한 곳에서 설정하는 함수입니다. HIGH는 켜기, LOW는 끄기를 의미합니다(일반적인 LED 연결 기준).

버튼 디바운싱

기계식 버튼은 누르거나 놓을 때 신호가 짧게 여러 번 튈 수 있습니다. 코드에서는 입력 변화 후 50ms가 지난 뒤 안정된 입력으로 처리합니다.

millis()를 이용한 2초 타이머

delay(2000)으로 프로그램 전체를 멈추는 대신, 노란불이 켜진 시각을 저장하고 경과 시간이 2000ms 이상인지 확인합니다. 따라서 루프가 계속 실행되며 버튼 입력도 확인할 수 있습니다.
